# Shravan Bahi (Broken Echoes)

A Discord VC-inspired aesthetic tribute and memory archive for Shravan.

## Features

- Ambient rain effects & sound generator
- Discord voice channel aesthetic interface
- Interactive memory logs, soundboard, and message archives
- Modern responsive glassmorphism UI with Tailwind CSS

## Live Preview / Usage

Open [index.html](index.html) (or `dedicated_to_shravan_broken_echoes.html`) directly in any modern web browser or host using GitHub Pages.
